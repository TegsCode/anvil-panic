# Screenshot shoot list

Ten stills and one GIF. Save them into this folder with **exactly** these names —
the README and the download page already point at them, so dropping the files in
is the whole job.

**Shape:** landscape, 16:9. Maximise the window (or `F11`), then screenshot the
window only — no desktop, no taskbar, no browser chrome. 1280×720 or bigger, PNG.
The page scales them, so bigger is fine, smaller is not.

## Classic build — `AnvilPanicClassic.exe`

| File | What to capture | How to get that moment |
|---|---|---|
| `classic-01-gameplay.png` | Early game, junk still spread out, blob mid-screen, score readable. | Start, wait ~5 s, screenshot. |
| `classic-02-shield.png` | The donut shield is up — three donuts circling the blob, one about to absorb a hit. | Collect three donuts, then screenshot with junk close. |
| `classic-03-death.png` | The flattened blob and the culprit sitting on top, score visible. | Die. Screenshot before pressing space. |
| `classic-04-late.png` | Late game — heavy junk hopping, lots of clutter, high score. | Survive ~30 s without dying. |

## New version — screenshots that hint at what is coming

Take these in the **current game** (`AnvilPanic.exe`), not the classic. Pick the
character with `C`, then fire the power with `E` and screenshot while the effect
is still on screen — the point of these is that people can see a power that the
classic build does not have.

| File | Character | Power to catch mid-effect |
|---|---|---|
| `tease-01-honoured.png` | THE HONOURED ONE | **Hollow Purple** — the beam / blast across the playfield |
| `tease-02-ninja.png` | THE NINJA | **Shadow Clones** — more than one of him on screen |
| `tease-03-titan.png` | THE TITAN | **Heat Vision** — the twin beams leaving his eyes |
| `tease-04-volt.png` | VOLT | **Thunder** — the strike / spark field |
| `tease-05-merc.png` | THE MERC | **Fourth Wall** — whatever the rewind breaks on screen |
| `tease-06-bat.png` | THE BAT | **Batarangs** — the thrown arcs |

If a power is too fast to catch with a screenshot, record a few seconds and pull
the frame from the video — that is easier than timing it.
