PHONE · BUTTONS

PHONE · TILT

Hold the phone roughly level and lean. Calibration happens on start.

PHONE · TOUCH

Tap and hold to steer where your thumb is. Swipe to drag the character across. Double-tap to dash.

LANDSCAPE

Before you ask

Windows says "Windows protected your PC"

The .exe is not code-signed — a certificate costs more per year than the game cost to make. Click More info, then Run anyway. The file is built straight from the source in this repository.

Android will not install the APK

Android blocks apps from outside the Play Store by default. When the prompt appears, tap Settings and allow installs from your browser or file manager, then tap the APK again. The build is self-signed, which is normal for anything not distributed through Google Play.

Where is my best score kept?

On the device, next to the game. Nothing is uploaded, and there is no account or network access at all.

iPhone?

There is no iOS build. The game is HTML and runs fine in Safari via the browser version, but Apple does not allow installing a standalone build without an App Store listing.

Can I see the source?

Yes — TegsCode/anvil-panic. The classic build is source-available under a noncommercial licence, so read it, run it and change it for yourself, but don't sell it or publish your own build.
